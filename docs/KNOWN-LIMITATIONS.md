# Известные ограничения

- Успешный HTTPS не доказывает UDP, QUIC, ICMP или исправность произвольного сайта.
- TLS-посредник, которому доверяет Windows, остается ограничением модели. Pinning чужих сертификатов не используется.
- Custom `ConnectCallback` записывает наблюдаемый IP и может отличаться от стратегии Happy Eyeballs по умолчанию.
- 24-часовой soak (T58) не выполнялся: компьютер нельзя оставлять включенным на сутки. Runner есть в `tools/Run-Soak.ps1`.
- Рестарт Explorer, sleep/resume и автозапуск в чужом HKCU требуют изолированной среды. Без успешного Windows Sandbox они остаются NOT RUN.
- Внешний 15-минутный smoke публичных сайтов не является зависимостью CI.
- Виртуальные 72 часа не заменяют реальные 24 часа.
