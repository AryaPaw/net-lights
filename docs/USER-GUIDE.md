# Руководство пользователя

Net Lights живет в области уведомлений. Левая половина круга - провайдер, правая - мир. Узкий вертикальный зазор прозрачный.

Цвета:

- зеленый: доступно (не менее двух независимых HTTPS-подтверждений)
- желтый: ограничено (ровно одно независимое подтверждение)
- красный: нет ответа (нет сети по сигналу Windows, либо несколько независимых HTTPS-направлений недоступны). Если группа уже была зелёной, красный может остаться и при неполной новой проверке, пока не появятся свежие подтверждения.
- серый: нет свежих данных

Это проверка HTTPS контрольных адресов, а не доказательство, что весь интернет или UDP/QUIC работают.

Меню трея: Открыть окно, Пауза, Выход. Автозапуск, автообновление и показ страны — во вкладке «Параметры». Показ страны в трее выключен по умолчанию. Если включить, рядом с кругом появляется вторая иконка из двух букв (например `DE`) или `??`. Размер букв там же: компактный, обычный или крупный. При наведении — только название страны по-русски и по-английски, через « / ». `??` если страну ещё не удалось узнать. Пауза монитора эту иконку не гасит. Там же кнопка «Проверить обновления»: сразу смотрит GitHub и ставит Setup, даже если автообновление выключено. Автозапуск включён по умолчанию и поднимает только значок в трее; окно открывается одним щелчком по значку или пунктом меню. Автообновление само скачивает Setup, ставит тихим установщиком и снова запускает программу в трей. Если проверка с GitHub срывается, повтор через две минуты. В шапке версия (`v…`) и значки Провайдер/мир. Разделы: Состояние, Локации, Диагностика, Параметры. Во вкладке «Локации» текущая карточка совпадает с буквами в трее. Ниже — смена стран с длительностью. Не пишутся IP и не пишется каждый новый адрес в той же стране. `??` в историю не попадает. Крестик прячет окно в трей; пауза и выход — из меню иконки. Ссылки на исходный код и Releases — во вкладке «Параметры».

Журнал в памяти: кольцо до 2000 событий и 2 МиБ, записи старше 48 часов удаляются. Поток проб и смена цвета групп на диск не пишутся. Экспорт собирает текущий снимок и журнал из памяти в ZIP по вашей команде.
