# Руководство пользователя

Net Lights живет в области уведомлений. Левая половина круга - провайдер, правая - VPN. Узкий вертикальный зазор прозрачный.

Цвета:

- зеленый: доступно (не менее двух независимых HTTPS-подтверждений)
- желтый: ограничено (ровно одно независимое подтверждение)
- красный: нет ответа (нет сети по сигналу Windows, либо несколько независимых HTTPS-направлений недоступны)
- серый: нет свежих данных

Это проверка HTTPS контрольных адресов, а не доказательство, что весь интернет или UDP/QUIC работают.

Меню трея: Открыть окно, Пауза, Выход. Автозапуск и автообновление — во вкладке «Параметры». Там же кнопка «Проверить обновления»: сразу смотрит GitHub и ставит Setup, даже если автообновление выключено. Автозапуск включён по умолчанию и поднимает только значок в трее; окно открывается одним щелчком по значку или пунктом меню. Автообновление само скачивает Setup, ставит тихим установщиком и снова запускает программу в трей. Если проверка с GitHub срывается, повтор через две минуты. В шапке версия (`v…`) и значки Провайдер/VPN. Разделы: Состояние, Узлы, Диагностика, Параметры. Крестик прячет окно в трей.

Журнал в памяти: кольцо до 2000 событий и 2 МиБ, записи старше 48 часов удаляются. Поток проб и смена цвета групп на диск не пишутся. Экспорт собирает текущий снимок и журнал из памяти в ZIP по вашей команде.
