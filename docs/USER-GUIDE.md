# Руководство пользователя

Net Lights живет в области уведомлений. Левая половина круга - РФ, правая - VPN. Узкий вертикальный зазор прозрачный.

Цвета:

- зеленый: доступно (не менее двух независимых HTTPS-подтверждений)
- желтый: ограничено (ровно одно независимое подтверждение)
- красный: нет ответа (нет сети по сигналу Windows, либо несколько независимых HTTPS-направлений недоступны)
- серый: нет свежих данных

Это проверка HTTPS контрольных адресов, а не доказательство, что весь интернет или UDP/QUIC работают.

Меню трея: Окно, Автозапуск, Автообновление, Выход. Автозапуск включён по умолчанию. Окно открывается при запуске. В шапке версия (`v…`) и значки РФ/VPN. Разделы: Состояние, Узлы, Диагностика, Параметры. Крестик прячет окно в трей.

Журнал в памяти: кольцо до 2000 событий и 2 МиБ, записи старше 48 часов удаляются. На диск пишется только смена цвета групп в `%LocalAppData%\NetLights\state-history.jsonl`, тоже не дольше 48 часов и не больше 4000 строк / 512 КиБ. Полный поток проб на диск не пишется. Экспорт собирает текущий снимок, память и историю в ZIP по вашей команде.
