# Разработка Net Lights

Пользовательское описание и снимки интерфейса находятся в [README](../README.md). Здесь собраны команды сборки и проверки текущей нативной версии.

## Подготовка

Нужны Windows 11 x64, PowerShell 7.5+, Rust с MSVC, Visual Studio Build Tools с C++ и Windows SDK. Версия Rust и компоненты закреплены в [`rust-toolchain.toml`](../rust-toolchain.toml), зависимости – в [`Cargo.lock`](../Cargo.lock). Нативное приложение использует Rust и GPUI Kit без WebView; прежняя реализация C# сохранена в `src/` для совместимости и подготовки промежуточного обновления.

## Сборка и локальный запуск

Из корня репозитория:

```powershell
pwsh -File scripts/run-local.ps1
```

Скрипт собирает приложение и агент, штатно завершает только локальную копию, заменяет её файлы транзакционно и запускает `artifacts/publish/NetLights.exe`. Установленную копию в AppData он не заменяет. Для сборки без последующего запуска используйте `-NoStart`.

Для быстрой итерации над интерфейсом используйте development-сборку с существующим каталогом артефактов:

```powershell
cargo build -p netlights-app --locked --target-dir artifacts/rust-target -j 4
```

Проверяйте оформление в отдельном профиле, не меняя рабочие настройки и историю. `--inspect-page state|locations|diagnostics|settings|about` вместе с `--profile-directory` и `--skip-automatic-updates` открывает собственное окно без активации. Завершайте этот экземпляр через `--exit-local` с тем же профилем. Это статический осмотр, а не проверка ввода или производительности Release.

## Проверка

Единый вход – [`scripts/verify.ps1`](../scripts/verify.ps1). Локальный предварительный прогон:

```powershell
pwsh -File scripts/verify.ps1 -Preflight
```

Он проверяет синтаксис PowerShell, самопроверки стенда, форматирование, строгий Clippy и тесты без GUI, включая frameprobe. Используются существующие `artifacts/rust-target` и `artifacts/frameprobe-target`.

Полный прогон `pwsh -File scripts/verify.ps1` дополнительно проверяет готовые exe, функциональный интерфейс и runtime coverage. Интерактивные проверки выполняются на одноразовой hosted Windows VM. `-NativeUI` запускает отдельный визуальный сценарий; результат относится к фактическому DPI сеанса. Предварительный прогон не подтверждает UI, установку или отсутствие утечек.

Подробности режимов и ограничений находятся в [процедуре проверки и выпуска](../.cursor/skills/net-lights-ship/SKILL.md), актуальные задания – в [GitHub Actions](../.github/workflows). Установка, автоматический прямой переход 1.6.0 → актуальная версия, переход через 1.6.1 и длительное измерение ресурсов являются отдельными сценариями. Прямой автоматический переход проверяет `AutomaticDirect`; передача файла агенту в `Direct` его не заменяет. `Latest` автоматически получает наибольшая публичная стабильная версия по числовому номеру. Повторная публикация bridge не меняет это правило. Не запускайте интерактивный стенд на рабочем столе пользователя без соответствующего разрешения.

## Логотип и снимки

Единственный исходник логотипа – [`native/assets/brand.svg`](../native/assets/brand.svg): форма 02-C, палитра 04 «Равновесие». Генерация прозрачных PNG и ICO для приложения, установщика и документации:

```powershell
pwsh -File scripts/generate-brand-assets.ps1
```

Ключ `-Check` проверяет соответствие ресурсов SVG в том же окружении. Рендер выполняется в отдельном headless-профиле Microsoft Edge без управления курсором. README использует SVG напрямую.

Снимки в `docs/images/window.png` и `docs/images/locations.png` получены из запущенной локальной сборки 1.7.0 на Windows 11. Это захват собственного окна через `PrintWindow` без активации, изменения пикселей и управления курсором. Использована отдельная копия настоящей истории; IP-адреса в кадр не попадают. Эти изображения показывают интерфейс, но не являются результатом полного тестового прогона.

`docs/images/tray.png` – исходная иллюстрация трея из коммита `57646f0`, восстановленная без изменения пикселей. Она показывает зелёный круг и пример кода страны `FI`, а не текущее состояние компьютера. Макет [`docs/images/tray-mock.html`](images/tray-mock.html) сохранён и сделан самодостаточным: значки встроены, внешние `tray-nl.png` и `tray-fi.png` не нужны. Цвета пяти SVG в `docs/images/tray-status-*.svg` сверены с `color` в `native/app/src/tray.rs`. В README сохранены исходные пропорции иллюстрации; снимки окон остаются настоящими.
