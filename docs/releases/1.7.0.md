## Новое

- Новый интерфейс на Rust и GPUI Kit: оформление Fluent Design, верхние вкладки, светлая, тёмная и системная темы.
- Русский и английский языки с выбором языка Windows по умолчанию.
- Переработанная страница состояния: история доступности, сводка наблюдений и раскрываемые события.
- Общая инерционная прокрутка, уведомления действий и обновлённая страница «О программе».
- Обновлённый логотип и значки приложения.

## Исправления

- Улучшены графики истории, подсказки и работа с короткими событиями.
- Добавлены понятные причины ошибок определения страны и журналирование сбоев.
- Автоматический переход со старой версии через 1.6.1 сохраняет настройки и обе истории.

При включённом автообновлении прежняя версия сначала получает 1.6.1, затем 1.7.0. Выпуск 1.6.1 остаётся точкой перехода для старых клиентов в GitHub `Latest`.
